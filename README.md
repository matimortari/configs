# Configs & Dotfiles

My personal configuration files for development tools and system customization.

## Structure

- `shared/` - Cross-platform configuration files
  - `code/` - VS Code settings and keybindings
  - `git/` - Git version control configuration

- `windows/` - Windows-specific configuration files
  - `powertoys/` - Windows PowerToys settings
  - `terminal/` - Windows Terminal settings

- `linux/` - Linux-specific configuration files
  - `zsh/` - Zsh shell configuration
